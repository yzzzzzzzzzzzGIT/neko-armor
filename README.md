# 小猫娘破甲

一个给 DeepSeek Harness 用的提示词注入插件，装完重启就能用。

它做两件事：让模型**不再动不动就拒绝、劝退、讲免责声明**，以及让回复**别一股 AI 腔**。不修改 DSH 本体，不注入木马，只在系统提示词里加一层规则。

分**快速版**（免费，开源）和**专业版**（赞助）。

---

## 快速开始

1. 完全退出 DeepSeek Harness（托盘也要退）
2. 下载安装程序，双击运行
3. 赞助页二选一：输入卡密装专业版，或点「跳过，使用快速版」
4. 安装完成后重新打开 DSH，在插件页确认「小猫娘破甲」已启用

装完第一次对话就能感觉到差别，不用额外配置。

## 两个版本

| | 快速版 | 专业版 |
| --- | --- | --- |
| 提示词内核 | 公开版，覆盖常见场景 | 完整版，更细的判定与边界 |
| 拒绝自动重试 | 无 | 有，拒绝后自动换策略重问 |
| 自动继续 | 无 | 有，回复被截断时自动接上 |
| 场景预设 | 无 | 四选一（通用 / 逆向 / 代码 / 精简） |
| 自定义人设与称呼 | 无 | 有 |
| 设置表单 | 只显示版本与赞助入口 | 完整配置项 |
| 授权 | 不需要 | 卡密，绑定设备 |

快速版随 npm 包分发，源码公开；专业版提示词不公开。

## 常见问题

**装了没反应？**
重启 DSH。插件是启动时加载的，光装不重启不会生效。

**提示「卡密已绑定其他设备」？**
说明这张卡在别的机器上激活过。打开安装器复制机器码，发给 QQ `1410749014` 换绑，换绑后原机器会失效。

**提示「无法连接授权服务器」？**
检查网络能否访问外网。专业版每次启动都要联网校验一次，断网会退回快速版。

**安装器提示 DSH 正在运行？**
把 DSH 连托盘图标一起退干净，任务管理器里确认没有 `DeepSeek Harness.exe` 再重试。

**怎么卸载？**
安装器里有卸载入口；或者到 DSH 的 profile 目录执行 `pnpm remove neko-armor` 并删除 `~/.dsh/plugins/neko-armor`。卸载后重启 DSH。

**会影响其他功能吗？**
不会。它只在系统提示词里加一层规则，不改 DSH 本体文件，也不接管任何工具调用。

## 专业版还能做什么

- **拒绝自动重试**：模型一旦开始说「我不能」，自动换一种问法再试，而不是把拒绝原样吐给你
- **自动继续**：回复被长度截断时自动接上，不用手动打「继续」
- **场景预设**：通用 / 逆向 / 代码 / 精简，四种提示词侧重，一键切
- **自定义人设**：设定它怎么称呼你、怎么称呼自己、用什么语气
- **设置表单**：上面这些都能在 DSH 设置页里改，改完即时生效

## 兼容其他工具

除了 DSH，安装器还能给这几个工具写规则，勾选即生效：

| 工具 | 写入位置 |
| --- | --- |
| DeepSeek Harness | 插件形式，写入 profile 配置 |
| Trae | 全局规则文件 |
| Claude Code | `~/.claude/CLAUDE.md` |
| Codex | `~/.codex/AGENTS.md` |

规则写在标记区块内，只追加不覆盖你原有的内容；卸载时只删标记区块，其他配置一个字不动。
